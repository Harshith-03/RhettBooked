# IPEDS institutional directory, Massachusetts

Saved 2026-10-18 for Hackachusetts.

Massachusetts institutions in the IPEDS 2024 institutional directory (HD2024). Street address and chief administrator are left out. Sector labels are the NCES sector codes. The live link is the national directory zip. data.csv is the Massachusetts slice.

Rows in data.csv: 144

Columns: unitid, name, city, sector, level, control, hbcu, size, website, latitude, longitude

How to use it

- Spreadsheets: open data.csv in Excel or Google Sheets.
- Fresh copy: run `python fetch.py` or `node fetch.js`. Both call the URL below and save the response.
- The preview on the Hackachusetts site is a few rows of this same table.

Direct request

https://nces.ed.gov/ipeds/datacenter/data/HD2024.zip
